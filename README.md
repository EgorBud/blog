# Стихи и музыка

Личный сайт со стихами и музыкой на GitHub Pages. Без сборки и зависимостей:
чистые HTML, CSS и JavaScript. Достаточно положить файлы в репозиторий —
и сайт работает.

## Что внутри

```
index.html            Главная: приветствие, последнее стихотворение, плеер
poems.html            Все стихи
music.html            Все треки с плеером
404.html              Страница «не найдено»
.nojekyll             Отключает обработку Jekyll на GitHub Pages
assets/
  css/style.css       Оформление (цвета и шрифты — в блоке :root)
  js/data.js          ВЕСЬ КОНТЕНТ: стихи и треки
  js/site.js          Логика: списки и плеер (обычно править не нужно)
  favicon.svg         Иконка сайта
  audio/              Аудиофайлы
    tihaya-voda-demo.wav  Демо-запись (можно удалить)
```

## Быстрый просмотр

Откройте `index.html` двойным щелчком — сайт полностью работает локально.

Если нужен локальный сервер (например, для проверки на телефоне):

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Как добавить стихотворение

Откройте `assets/js/data.js` и добавьте новый блок в начало массива `poems`:

```js
{
  title: "Название стихотворения",
  date: "2026-12-01",   // или "" — тогда дата не показывается
  text: [
    "Первая строка",
    "Вторая строка",
    "",
    "Новый абзац"
  ].join("\n")
}
```

Сохраните файл и обновите страницу. Стихи сортируются по дате: новые сверху.
Ссылка на конкретное стихотворение появляется автоматически,
например `poems.html#nazvanie-stihotvoreniya`.

## Как добавить трек

1. Положите файл в `assets/audio/`, например `assets/audio/moy-trek.mp3`.
   Имя лучше писать латиницей, без пробелов: `moy-trek.mp3`.
2. Добавьте блок в массив `tracks` в `assets/js/data.js`:

```js
{
  title: "Название трека",
  description: "Пара слов о записи",
  src: "assets/audio/moy-trek.mp3"
}
```

3. Сохраните и обновите страницу.

Демо-трек `tihaya-voda-demo.wav` можно удалить: уберите его блок из `data.js`
и удалите сам файл.

### О форматах и размерах

- Лучше всего подходит **MP3**, 128–192 кбит/с — хороший баланс качества и веса.
- GitHub Pages отдаёт файлы как есть. Ограничение GitHub: **до 100 МБ на файл**
  и около **1 ГБ на весь сайт**. Музыку лучше сжимать.
- Загружайте только свою музыку или записи, на которые у вас есть права.

## Как поменять название сайта

Название встречается в тексте страниц. Замените `Стихи и музыка` на своё
в файлах `index.html`, `poems.html`, `music.html`, `404.html`
(в шапке, подвале и тегах `<title>` / `<meta>`). Там же можно поправить
приветственный текст на главной.

Цвета и шрифты меняются в самом начале `assets/css/style.css`, в блоке `:root`:

```css
--bg: #faf7f2;      /* фон */
--ink: #211f1b;     /* основной текст */
--muted: #6f685e;   /* второстепенный текст */
--accent: #9c4b2c;  /* акцент */
```

## Публикация на GitHub Pages

### 1. Создайте репозиторий

На GitHub: **New repository**. Имя — латиницей, например `poems-and-music`.
Не добавляйте README и `.gitignore` (они уже есть локально).

### 2. Загрузите файлы

В папке сайта выполните (замените логин и имя репозитория):

```powershell
git init
git add .
git commit -m "Сайт: стихи и музыка"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
git push -u origin main
```

### 3. Включите Pages

В репозитории: **Settings → Pages**

- **Source**: `Deploy from a branch`
- **Branch**: `main`, папка `/ (root)`
- **Save**

Через 1–2 минуты сайт будет доступен по адресу:

```
https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПОЗИТОРИЙ/
```

Если назвать репозиторий `ВАШ_ЛОГИН.github.io`, адрес будет короче:
`https://ВАШ_ЛОГИН.github.io/`.

### 4. Обновление сайта

После правок достаточно выполнить:

```powershell
git add .
git commit -m "Новые стихи"
git push
```

Обновление на GitHub Pages занимает минуту-две.
Если изменения не видны — обновите страницу с Ctrl+F5.

## Свой домен (необязательно)

В **Settings → Pages → Custom domain** укажите домен, например `stihi.ru`
(лучше свой). GitHub создаст файл `CNAME` — не удаляйте его.
У регистратора добавьте CNAME-запись на `ВАШ_ЛОГИН.github.io`.

- Собственный минималистичный плеер: play/pause, перемотка, время, скачивание.
- Одновременно играет только один трек.

- Тёмная/светлая системная тема не ломает вид (сайт всегда светлый, как задумано).
- Печать страницы со стихами без лишних элементов.
